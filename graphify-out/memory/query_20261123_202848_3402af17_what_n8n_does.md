# Q: what n8n does

## Answer

FleetFlow uses n8n as an orchestration layer for two workflows. Shipment Handover receives an authorized handover event, validates its shape, and calls the protected FleetFlow integration endpoint with the shared secret. FleetFlow remains the source of truth and transactionally changes the driver, resets assignment acceptance to PENDING, writes StatusLog, and stores the unique HandoverEvent for idempotency. Team Activity accepts START_TASK, GitHub push, and pull-request events, normalizes them, and optionally forwards them to TEAM_NOTIFICATION_WEBHOOK_URL, returning notified false when no target is configured.
